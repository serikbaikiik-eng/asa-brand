# ASA BRAND — магазин и админ-панель (один сайт)

Магазин:  http://localhost:5000
Админка:  http://localhost:5000/admin  (ссылка «Admin» есть внизу магазина)

## Запуск на компьютере
    pip install -r requirements.txt
    python app.py

## Логин и пароль
При первом входе на /admin сайт сам предложит создать логин и пароль (пароль от 8 символов).
Это делается один раз. Потом входите с ними. Поменять логин/пароль: админка → «Аккаунт».
Забыли пароль: остановите сайт и выполните `python app.py --reset-admin`, затем снова откройте /admin.

## Хостинг (Render, Railway, PythonAnywhere, VPS)
    gunicorn app:app
Первую настройку на хостинге защищает ключ: задайте переменную SETUP_KEY (любая длинная строка),
откройте /admin и введите ключ вместе с новым логином и паролем.
Либо задайте ADMIN_LOGIN и ADMIN_PASSWORD (от 8 символов), админ создастся сам.
Ещё: SECRET_KEY (длинная случайная строка), WHATSAPP (по умолчанию 77051511150), DB_PATH (файл базы на постоянном диске).

## Для продажи магазина клиенту
- Запускайте с NO_DEMO=1 — тогда сайт будет без демо-товаров, клиент добавит свои в админке.
- Название, цвет, контакты, боксы и тексты меняются в «Настройках», товары — в «Товарах и ценах». Инструкция для клиента: ИНСТРУКЦИЯ_ДЛЯ_ВЛАДЕЛЬЦА.md.

## Важно
- Заказы лежат в файле shop.db. Делайте его копии. Новая версия кода работает со старой базой.
- На хостинге нужен HTTPS.
